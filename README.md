# Nombre del proyecto.
Disonancia Armónica
# Descripción breve.
Una tienda de instrumentos musicales creada en React.
# Tecnologías utilizadas.
- **[React 18](https://react.dev/)**: Biblioteca principal para la construcción de interfaces de usuario.
- **[Vite](https://vitejs.dev/)**: Entorno de desarrollo y compilador.
- **[React Router DOM v6](https://reactrouter.com/)**: Manejo de rutas y navegación dinámica utilizando `HashRouter`, `Routes`, `Route`, `Link` y el hook `useParams`.
- **[React-Bootstrap](https://react-bootstrap.netlify.app/) & [Bootstrap 5](https://getbootstrap.com/)**: Framework de estilos para el diseño responsivo, sistema de grillas (`Container`, `Row`, `Col`) y componentes interactivos (`Navbar`, `Card`, `Modal`, `Table`, `Form`, `Badge`).
- **[LocalStorage API](https://developer.mozilla.org/es/docs/Web/API/Window/localStorage)**: Persistencia en el navegador del estado del carrito de compras.
- **[gh-pages](https://www.npmjs.com/package/gh-pages)**: Despliegue de la aplicación en GitHub Pages.

# Instrucciones para instalar y correr el proyecto.
- Clonar el repositorio.
- Instalar las dependencias: 
   ```bash
   npm install
   ```
- Iniciar el proyecto:
   ```bash
   npm run dev
   ```
